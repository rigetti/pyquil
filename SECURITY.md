# Security Policy

## Supported Versions

Security updates are only applied to the latest major version.

| Version | Supported |
| ------- | ------------------ |
| >= 4.0 | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

Use GitHub's reporting tool: https://github.com/rigetti/pyquil/security/advisories
